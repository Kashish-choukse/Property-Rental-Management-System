# Property Rental Management System

A web-based Property Rental Management System developed using Java, Spring Boot, Oracle Database, HTML, CSS, and JavaScript.

The system allows property owners to manage their properties and tenants to search and rent available properties. It also provides secure user authentication using JWT.

## Features

- User registration and login
- JWT-based authentication
- Role-based access for Owners and Tenants
- Add, update, view, and delete properties
- Search properties by location
- Filter properties by type and maximum rent
- Rent available properties
- View rental details
- Complete or cancel rentals
- Property availability management
- Validation and error handling
